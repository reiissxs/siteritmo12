# Ritmo 12 — Landing Page

Landing page independente do aplicativo Ritmo 12.

## Arquivos
- `index.html` — página de vendas completa
- `assets/ritmo12-logo.png` — logo
- `vercel.json` — configuração simples para Vercel

## Fluxo de preços
- Vitalício: R$ 27,90 pagamento único
- Mensal: R$ 14,90/mês
- Ao selecionar o mensal e clicar em assinar, abre uma oferta especial para trocar por vitalício por R$ 19,90 total (+R$ 5 em relação ao primeiro mês).
- Recusando a oferta, o fluxo segue com o mensal.

## Checkout
Os botões estão em modo demonstração. Substitua a função `demoCheckout()` pelos links/integração do gateway quando definidos.
